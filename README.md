# Playerok Manager

Локальная панель управления магазином Playerok для Windows: объявления, конкуренты, комиссии, расчёт цен, расписания премиума, заказы и финансы. Для Telegram NFT Gifts доступны каталог MRKT и подготовка автовыдачи. Обычные товары не запускают закупку NFT и выдачу.

## Установка

Требуются **Windows 10/11, Python 3.12+, Node.js 22.9+ и Git**, доступные в PATH. Docker не требуется.

1. Скачайте исходники в отдельную папку.
2. Запустите `setup.bat`: установка зависимостей, подготовка SQLite и сборка интерфейса.
3. Запустите `run.bat` и откройте **http://localhost:3100**.
4. Создайте пароль администратора. Откройте **Настройки → Подключения**.

`stop.bat` останавливает приложение, `status.bat` показывает состояние. Воркер работает при закрытом браузере, пока включён компьютер. API: `127.0.0.1:8101`.

## Настройка через панель

Редактировать `.env` для обычной установки не требуется. Доступны Playerok cookies, Telegram-бот и владелец, вход в личный Telegram по номеру, коду и паролю двухэтапной проверки, подключение MRKT через эту сессию, прокси, комиссии, стоимость Stars, лимиты и пароль администратора.

**[Пошаговая инструкция](docs/SETUP.md)** также доступна из настроек. **[Разработка и импорт прототипа](docs/DEVELOPMENT.md)**, **[защита данных](SECURITY.md)**.

Первый запуск — **Dry Run**: чтение и расчёты доступны, торговые изменения заблокированы на сервере. Покупки, передачи, изменение цен и платные поднятия включаются отдельно. Не запускайте несколько исполнителей одного магазина или polling одного бота одновременно.

## Возможности и ограничения

Для NFT привяжите точную пару «коллекция — модель», настройте и подтвердите комиссии, стоимость Stars и прибыль. Котировки одинаковых пар запрашиваются совместно; устаревшие данные блокируют автоматические действия. TON/RUB обновляется через CoinGecko. Исторические операции сохраняют свои курсы и комиссии.

Премиум покупается для существующего активного лота по актуальному тарифу. Есть предварительный расчёт, массовое создание расписаний, лимит одной покупки и дневной бюджет. Расходы отражаются отдельно.

Автозакупка и MTProto-передача реализованы, но **сквозной тест с реальной покупкой и передачей не выполнен**. Перед включением требуется отдельная проверка владельцем. При неопределённом ответе денежный запрос не повторяется автоматически: требуется сверка результата или ручная обработка.

Изменение количества, отключение и удаление объявлений могут требовать ручного действия на Playerok: непроверенные операции обозначаются явно. Первичная синхронизация не исполняет старые оплаченные заказы. Импортированные ручные задания остаются ручными.

## Данные

SQLite WAL, локальное шифрование секретов отдельным ключом. Сохраняйте **базу, ключ и файлы сессий вместе** в защищённом месте. Резервные копии SQLite: `data/backups`, последние семь. Потерянный ключ восстановить невозможно.

`data`, `.env`, HAR, сессии и ключи исключены из публикации. Публичная копия не содержит подключённого магазина или личных товаров. Лицензия проекта не выбрана; уведомления зависимостей сохранены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
