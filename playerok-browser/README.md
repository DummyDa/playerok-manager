# Обычные лоты Playerok

Полностью самостоятельный подпроект. Не импортирует основной backend, не читает его базу, настройки, cookies или сессии и не запускается основным run.bat.

Запуск на Windows: **playerok-browser\run.bat**. При первом запуске создаётся собственная `.venv` и устанавливается `curl-cffi`. Сайт открывается на **http://127.0.0.1:3190**. Остановка — Ctrl+C в его консоли.

Показываются публичные объявления категории **Telegram → Подарки (NFT)** с изображением, ценой, скидкой, названием, рейтингом и количеством отзывов продавца. Клик открывает исходный лот на Playerok. Покупок и изменений аккаунта нет.

API Playerok запрашивается с `priority: DEFAULT` и `status: APPROVED`; перед отображением эти значения проверяются повторно. Неизвестный приоритет не считается обычным. Аккаунт не требуется. Страницы кэшируются на минуту, внешние запросы идут последовательно с интервалом не менее двух секунд. При блокировке API показывается ошибка, а не вымышленные лоты.

Ручной запуск на любой поддерживаемой системе:

```text
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

На Windows путь интерпретатора: `.venv\Scripts\python.exe`. Дополнительный порт: `server.py --port 3191`. Категория задана константой CATEGORY в server.py. GraphQL hash и ID категории — публичные идентификаторы протокола, а не секреты; при изменениях Playerok их может потребоваться обновить.
