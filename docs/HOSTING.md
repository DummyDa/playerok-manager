# Публикация каталога

Основной запуск создаёт четыре процесса: панель 3100, API 8101, каталог 3180 и воркер. Все HTTP-службы слушают loopback. `run.bat`, `stop.bat` и `status.bat` управляют всеми службами. На Linux используется тот же супервизор: `.venv/bin/python scripts/launcher.py start --no-browser`.

## Адрес и HTTPS

1. Направьте DNS своего домена на VPS.
2. В панели сохраните **Каталог → Адрес каталога для покупателей** как `https://ваш-домен`, без пути. Это адрес в сообщениях и разрешённый публичный Host каталога.
3. Настройте HTTPS reverse proxy к `127.0.0.1:3180`, сохраняя исходный Host. Не направляйте каталог на административный порт 3100 или API 8101.
4. Закройте извне порты 3100, 8101 и 3180. TLS, лимиты соединений и защиту от массовой нагрузки настройте на прокси/firewall.

Пример блока nginx **внутри уже настроенного HTTPS virtual host с вашим сертификатом**:

```nginx
location / {
    proxy_pass http://127.0.0.1:3180;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_read_timeout 65s;
    client_max_body_size 1m;
}
```

Приложение не использует forwarded IP как доказательство личности. Посетители за одним прокси делят лимит адреса соединения; глобальные лимиты работают независимо от заголовков. Для большого трафика настройте дополнительные лимиты по реальному клиентскому IP на самом прокси, затем согласуйте размеры внутренних бюджетов с нагрузкой.

## Панель владельца

Рекомендуется не публиковать панель и открывать её через SSH-туннель:

```powershell
ssh -L 3100:127.0.0.1:3100 user@SERVER_IP
```

Откройте `http://127.0.0.1:3100`. Проброс API не нужен: панель сама обращается к нему.

Если нужен публичный административный домен, используйте отдельный HTTPS-host и настройку PUBLIC_ORIGIN. Перед публикацией создайте пароль. При включённом PUBLIC_ORIGIN создание первого пароля по HTTP запрещено даже через прокси; выполните на сервере:

```text
.venv/bin/python scripts/bootstrap_admin.py
```

На Windows: `.venv\Scripts\python.exe scripts\bootstrap_admin.py`. Пароль вводится интерактивно без отображения и не принимается в аргументах. Существующий пароль скрипт не меняет.

## Перенос данных

Остановите старый экземпляр перед переносом: два воркера одного магазина одновременно не запускайте. Приватно перенесите корневую `data` вместе с ключом `secrets.key` и нужными сессиями. Без ключа сохранённые секреты не расшифровать. Кэш `catalog/data` переносить необязательно. При смене IP сервисы могут потребовать повторный вход.

Каталог и воркер работают под одним владельцем и имеют общую учётную запись MRKT; это не изоляция от компрометации хоста. Доступ к файловой системе VPS, резервным копиям и SSH ограничивайте владельцем.
