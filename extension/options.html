Telegram Web → Playerok

В настройках Playerok Manager получите одноразовый код и вставьте сюда. Срок действия — 5 минут.

Расширение создаёт отдельную неактивную вкладку Telegram Web A. Один раз войдите в тот же Telegram-аккаунт, на который выводятся подарки с MRKT. Chrome должен оставаться запущенным.

Расширение не поднимает окна и не активирует вкладку. Если интерфейс Telegram изменился, передача останавливается для ручной проверки.
