# Каталог Telegram Gifts

Запуск: корневой **run.bat**. Панель: http://127.0.0.1:3100, каталог: http://127.0.0.1:3180. Корневые stop.bat и status.bat управляют всеми четырьмя службами. catalog/run.bat также запускает всё приложение; отдельный сервер не требуется.

Каталог использует реальные настройки, балансы и очередь основного проекта. Цены рассчитываются с учётом наценки, курса TON, комиссий и передачи; премиум не учитывается. Кнопка покупки ставит запрос в основную очередь. Воркер проверяет точный NFT и актуальную цену, создаёт временный лот Playerok с изображением 1280×960 и описанием из настроек. Лот действует 15 минут. Закупка и передача начинаются после подтверждённой оплаты и при включённых разрешениях. Код заказа применяет реальный баланс; остаток сохраняется. Старые тестовые коды не превращаются в реальные деньги. Неизвестные результаты денежных операций требуют сверки.

## Публичный адрес

В основной панели сохраните Каталог → Адрес каталога для покупателей: https://ваш-домен без пути. Сервер разрешит этот Host и Origin. HTTPS reverse proxy должен направлять запросы на 127.0.0.1:3180, сохраняя Host; внутренние порты не публикуются. Локальный адрес разрешён для проверки на своём компьютере. Подробнее: [хостинг](../docs/HOSTING.md).

## Данные и нагрузка

Основная база, ключ и сессии находятся в корневой data. Кэш предложений и изображений — в catalog/data; при переименовании catalog-demo в catalog кэш сохраняется. Обе папки игнорируются Git. Коллектор читает настройки и использует общий атомарный резерв запросов MRKT с воркером. Обработчики checkout и кодов пишут реальные намерения и резервы баланса в основную базу.

Запросы ограничиваются по адресу соединения и глобально без доверия forwarded IP. Посетители за одним прокси могут делить лимит. Одновременно допускается до 20 активных запросов публикации. Оплаченные заказы имеют приоритет перед новыми лотами. Проверка одного NFT кратковременно кэшируется; загрузки изображений и анимаций ограничены по параллельности. Для публичной нагрузки нужны дополнительные ограничения reverse proxy. Каталог не предоставляет административные маршруты.

## Проверки без денежных операций

Один посетитель может держать не более пяти временных лотов. Лимит проверяется атомарно по серверной cookie посетителя и хешу IP; попытки из нескольких вкладок учитываются вместе. Для текущего Quick Tunnel IP берётся из заголовка Cloudflare только на разрешённом адресе trycloudflare и при локальном подключении туннеля. Произвольный X-Forwarded-For не используется. За обычным reverse proxy посетители могут делить лимит адреса прокси.

Очередь создания также занимает место. Неоплаченный лот освобождает его после окончания 15 минут и подтверждённого снятия. Оплаченный лот удерживает место до своего исходного срока. Сбой до публикации место не занимает; неизвестный результат требует сверки. Повторное открытие готового лота не расходует ещё одно место. Лимит действует для новых запросов, привязанных к посетителю.

Из папки catalog:

```powershell
..\.venv\Scripts\python.exe -m pytest test_catalog.py -q
node paid-choice-smoke.cjs
node checkout-smoke.cjs
```

Оба checkout smoke-теста подменяют финансовые запросы и не создают реальные оплаты, лоты и закупки.
