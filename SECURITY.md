# Приватные данные

Не публикуйте cookies, токены BotFather, API Hash, коды Telegram, пароль 2FA, StringSession, `.session`, `.env`, базы, ключи шифрования или HAR.

Обычные issues предназначены только для обезличенных ошибок. Если обнаружили утечку собственных реквизитов, сначала отзовите cookies/токен/Telegram-сессию у соответствующего сервиса и замените их в панели. Удаление файла из последнего commit не удаляет его из истории Git.

Панель предназначена для локального использования одним администратором. Пароли хешируются scrypt, сеансы серверные, изменяющие запросы проверяют CSRF и разрешённый Origin. Настройка внешнего HTTPS-доступа и защита компьютера остаются у владельца.

Покупательский каталог запускается отдельно от административного API общим `run.bat`. Все службы слушают только loopback. Для публикации каталога настройте HTTPS-прокси к порту 3180 с сохранением Host и укажите его адрес в настройках каталога. Панель рекомендуется открывать через SSH-туннель, не публикуя порты 3100/8101. Настройки и секреты не доступны через API каталога. Приложение не является защитой от распределённой перегрузки: лимиты прокси и firewall дополняют встроенные ограничения.

В режиме PUBLIC_ORIGIN первоначальная установка пароля по HTTP запрещена: используйте интерактивный `python scripts/bootstrap_admin.py` на сервере. Существующий пароль не меняется. Административный API не доверяет forwarded IP; глобальный бюджет попыток входа атомарный и хранится в базе. При проксировании запросы могут иметь общий адрес и общий лимит — forwarded-заголовки не дают дополнительного бюджета.

Fernet защищает сохранённые секреты отдельно от ключа; это не защита от человека, уже имеющего доступ ко всей папке `data` и к `secrets.key`. Резервные копии храните приватно. Отзывайте ненужные Telegram-авторизации через Telegram → Устройства.

Новые подключения и финансовые действия разделены. Первоначально включён предварительных расчётов; добавление аккаунтов не разрешает покупки или передачу. При неопределённом результате денежный запрос не повторяется без сверки.
